# Little Wins Wall

Build littlewins, a minimalist public wall of small personal victories.

The core experience is a beautiful responsive grid of anonymous cards containing short “little wins”.

No likes, no comments, no profiles, no followers, no social metrics.

The site should feel calm, warm, human and slightly playful — not like a social network, productivity app or SaaS dashboard.

At the top:
“189,763 little wins since March 16, 2026”

Below it, a responsive masonry/grid of cards, newest first.

A prominent but simple “+ My little win” action lets someone anonymously submit one.

The first version should use mock data only. Focus on the visual experience and responsive layout before implementing the backend.

Support English and French from the beginning, with littlewins remaining the product name in both languages.
