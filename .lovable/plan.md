# Refine the littlewins public wall

## Goal
Keep the existing littlewins concept and interactions, while shifting attention away from a landing-page-style introduction and toward the anonymous wall itself.

## Changes
- Simplify the top bar into a quiet, non-sticky header with the wordmark, language switcher, and one “+ My little win” action.
- Recompose the introduction as a compact editorial sentence: the count, “little wins,” and the start date will read together as context rather than a large display statistic.
- Shorten and soften the supporting copy while preserving both English and French.
- Bring the wall closer to the introduction and give it more vertical presence.
- Retain the masonry layout: three columns on desktop, two on tablet, and one on mobile, with newest items appearing first in reading order.
- Make note sizing feel less rigid through restrained spacing variation while keeping scanning comfortable.
- Subdue borders, shadows, pins, and hover movement so each written win remains the strongest element.
- Keep the existing submission modal, but visually align it with the quieter page and ensure the single header action opens it.
- Reduce the footer to a low-key closing line that does not compete with the wall.
- Preserve restrained entrance motion and add reduced-motion handling.

## Verification
- Check desktop, tablet, and mobile widths for hierarchy, spacing, readable cards, overflow, and modal behavior.
- Confirm English/French switching, newest-first order, and local mock submission still work.

## Technical details
- Update only the page presentation, translations, and global visual tokens/utilities.
- No authentication, storage, backend, analytics, or social features will be added.
